# Vitta — protótipo de e-commerce

## Como executar
1. Extraia `vitta-ecommerce.zip`.
2. Abra `index.html` no navegador. Não precisa instalar dependências.

## O que está incluído
- Página inicial responsiva com catálogo, avaliações e selos de confiança.
- Carrinho com quantidade, subtotal e indicador de frete grátis acima de R$ 199.
- Simulação demonstrativa de frete por CEP antes do checkout.
- Checkout de uma página, como convidado, com validação de campos.
- Pix com desconto de 5%, cartão e carteira digital como opções de interface.
- Resumo de pedido e confirmação demonstrativa.

## Importante
Este é um protótipo front-end. Os produtos, avaliações, preços, fretes e dados de contato são exemplos fictícios para demonstração. O site não envia pedidos, não cobra pagamentos, não consulta um serviço real de CEP e não envia e-mails de recuperação. Para produção, integrar backend, estoque, transportadora/Correios, gateway de pagamento, autenticação administrativa, política real de privacidade e consentimento LGPD.

## Recuperação de carrinho (conforme proposta)
A régua de e-mail automatizada em 2h, 24h e 48h e o remarketing precisam de backend/CRM e consentimento apropriado. O protótipo não dispara mensagens automaticamente.
